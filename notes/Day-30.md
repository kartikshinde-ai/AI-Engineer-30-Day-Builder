⚠️ 3. 5 Mistakes I Made
1. Focusing more on making workflows work than documenting them

I learned that documentation should be maintained along with development instead of leaving it until the end.

2. Tool input schema mismatch

One of the Project 4 agent tools initially had an input type mismatch between the schema and the value generated by the model.

Lesson

Tool schemas must be clear and consistent with the values expected by the tool.

3. Ollama connection failure

The AI Agent initially encountered an Ollama connection error (fetch failed).

Lesson

Local AI systems also require debugging of connections and dependencies.

4. Assuming AI output is always correct

During the projects, I learned that AI-generated results should be tested instead of automatically being treated as correct.

Lesson

AI systems need validation and testing.

5. Learning the importance of human control

Automation should not automatically perform important or irreversible actions without appropriate control.

Lesson

Human approval can be an important safety layer in AI workflows.
