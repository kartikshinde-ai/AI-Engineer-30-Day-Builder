# Day 05 — Prepare Documents for RAG

## Goal

Understand how documents become searchable pieces for a RAG system.

---

## 1. Chunking

Chunking is the process of breaking a large document into smaller meaningful pieces called chunks.

### Simple Explanation

Instead of giving the complete document to the AI, we divide it into smaller sections so that the RAG system can retrieve only the relevant information.

### Example

- Chunk 1 → Admission Rules
- Chunk 2 → Fees Structure
- Chunk 3 → Scholarship Rules
- Chunk 4 → Attendance Rules

### Why Chunking is Important

- Improves retrieval
- Reduces irrelevant context
- Helps the system find relevant information
- Makes large documents easier to process

### Too Small vs Too Large

Too Small:
- Context may be incomplete
- Meaning can be lost

Too Large:
- More irrelevant information may be retrieved
- Retrieval can become less precise

---

## 2. Metadata

Metadata is additional information about a document or chunk.

### Example

Content:

"Scholarship applications are submitted through the portal."

Metadata:

- Source: scholarship_rules.pdf
- Topic: Scholarship
- Page: 5
- Document Type: PDF

### Why Metadata is Useful

- Helps organize documents and chunks
- Helps filter relevant information
- Makes sources easier to identify
- Provides context about retrieved content

### Chunk vs Metadata

Chunk:
The actual information stored for retrieval.

Metadata:
Additional information that describes the chunk.

---

## 3. Embeddings

Embeddings are numerical representations of text that help AI systems compare the meaning and similarity of text.

### Simple Flow

```text
Text
  ↓
Embedding Model
  ↓
Numerical Representation

Example
"Python is a programming language."
              ↓
       Embedding Model
              ↓
      [0.21, -0.48, 0.73, ...]

The numbers are generated by an embedding model and are used by the system to compare text similarity.

Why Embeddings are Useful in RAG
Convert text into numerical representations
Help compare semantic similarity
Make similarity-based retrieval possible
Connect document chunks with user queries
Embeddings in the RAG Pipeline
Documents
    ↓
Chunks
    ↓
Embeddings
    ↓
Vector Store
    ↓
Retrieval
4. Retrieval

Retrieval is the process of finding relevant document chunks from the knowledge base based on a user's query.

Simple Flow
User Question
      ↓
Search Knowledge Base
      ↓
Find Relevant Chunks
      ↓
Retrieve Context
      ↓
Send Context to LLM
Why Retrieval is Important
Finds relevant information from the knowledge base
Reduces irrelevant context
Provides useful context to the LLM
Helps generate grounded answers
Example

If the user asks:

"How do I learn Python?"

The retrieval system should find relevant chunks about Python learning instead of returning unrelated document content.

RAG Flow
Documents
    ↓
Chunks
    ↓
Embeddings
    ↓
Vector Store
    ↓
Retrieval
    ↓
Relevant Context
    ↓
LLM
    ↓
Answer
