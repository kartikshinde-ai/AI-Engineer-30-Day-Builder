## Goal

Generate different social media post styles from the same real project facts.

## What I Understood

- Post structure keeps the generated content organized.
- Factual consistency is important when generating different versions from the same source.

- Generated three versions for the same topic:

  3. Short
- Checked the factual claims against `content_inputs.md`.
- Ensured that no personal experience, result or achievement was invented.
