## Project Selected

Project 2 — AI Lead Automation

I selected Project 2 because it is one of my strongest completed projects.

## What I Built

I built an AI-assisted lead automation workflow using:

- n8n
- JavaScript
- AI processing
- Google Sheets

The workflow processes lead information, classifies leads, prepares a draft reply, waits for human approval, and handles follow-up processing.

## Problem Solved

The workflow helps reduce repetitive lead-processing work and provides a structured way to manage lead classification, replies, approval, and follow-ups.

## Challenge I Faced

In the follow-up workflow, the expected lead was not identified because the follow-up date was entered in the wrong field.

I fixed this by using the correct `next_followup_date` field and testing the workflow again.

## Main Lesson

My biggest lesson was:

> Test each workflow step and verify that the actual data fields contain the expected values.
