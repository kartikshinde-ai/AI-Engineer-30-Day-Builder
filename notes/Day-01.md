# 🧠 Day 01 Self-Check — Answers

### 1. Where are my AI projects stored?

My AI projects are organized inside the `AI-Engineer-30-Day-Builder` repository in separate project folders.

### 2. Where are my daily notes stored?

My daily learning notes are stored inside the `notes/` folder.

Example:

`notes/Day-01.md`

### 3. What is README.md used for?

`README.md` is the main documentation file of the repository. It explains what the project is, its purpose, structure, and important information.

### 4. What is a Git repository?

A Git repository is a project workspace managed by Git that keeps track of project files and their history.

### 5. Why is .gitignore important?

`.gitignore` tells Git which files or folders should not be tracked or uploaded to the repository.

It helps prevent sensitive, temporary, or unnecessary files from being committed.

### 6. Why must API keys remain private?

API keys are credentials that can provide access to external services. If exposed publicly, someone else could misuse them.

Therefore, real API keys should never be committed to GitHub.

### 7. Where will future projects be organized?

Future projects will be organized inside separate project folders such as:

- `project-1-rag/`
- `project-2-leads/`
- `project-3-social/`
