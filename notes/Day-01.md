# 1. GitHub

## What is GitHub?

GitHub is an online platform used to store, manage, share and showcase
Git repositories.

### Why am I using GitHub?

I will use GitHub to:

- Store my AI Engineer projects
- Track my project progress
- Maintain project documentation
- Showcase my work as a portfolio
- Keep my projects organized

### AI Engineer Connection

A professional AI Engineer should not keep projects only on a local
computer. Projects should be properly organized, documented and
version-controlled.

---

# 2. Git Repository

## What is a Repository?

A repository is a project workspace managed using Git.

It contains the project's:

- Code
- Documentation
- Notes
- Configuration files
- Project history
