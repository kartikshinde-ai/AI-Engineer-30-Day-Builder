# RAG Knowledge Assistant — Test Questions

## Answerable Questions

1. What is Python?
2. What are the basic features of Python?
3. What is Artificial Intelligence?
4. What is Machine Learning?
5. What is the difference between AI and Machine Learning?
6. What is supervised learning?
7. What is unsupervised learning?
8. What is Retrieval-Augmented Generation (RAG)?
9. Why is document retrieval useful in a RAG system?
10. What is the role of a language model in a RAG system?

## Unanswerable Questions

11. Who is the current Prime Minister of India?
12. What is today's weather in Maharashtra?
13. What is the current price of Bitcoin?
14. Who won the latest cricket match?
15. What is the latest news today?

## Expected Fallback Behavior

If the required information is not available in the provided documents,
the assistant should clearly state that it could not find the answer
in the provided documents.

The assistant should not invent, guess, or fabricate an answer.
